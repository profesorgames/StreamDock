StreamDock — автономный загрузчик для Windows 10/11 x64.

**Скачайте `StreamDock.exe` и запустите. Установка, Python, .NET и FFmpeg не нужны.**
Первый запуск распакует и проверит встроенные компоненты в папке текущего пользователя.

- Видео с выбором разрешения, аудио MP3 128–320 кбит/с, изображения/галереи, прямые файлы.
- Очередь, прогресс, отмена, повтор и история. До четырёх загрузок одновременно.
- Трей; необязательный автозапуск Windows сразу в трей.
- Spotify: вход через браузер с PKCE, текущая песня, выбор подходящей записи YouTube и сохранение MP3.
- Русский интерфейс, тёмная тема, плавные переходы и индикаторы прогресса.

Для Spotify нужен Client ID вашего приложения в Spotify Developer Dashboard и Redirect URI
`http://127.0.0.1:43829/callback/`. Секрет приложения не требуется. Токены защищены Windows DPAPI.
Spotify предоставляет только метаданные; загрузка идёт из выбранного внешнего источника.

Поддержка конкретных сайтов зависит от их доступности и изменений на их стороне. Для страниц,
требующих входа, можно указать свой cookies.txt. Защищённые DRM-потоки не поддерживаются.
EXE не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.

Рядом опубликован SHA256SUMS.txt. Windows CI проверяет EXE в изолированной папке: все встроенные
инструменты, локальную HTTP-загрузку, конвертацию настоящего MP3 и его проверку ffprobe,
интерфейс, закрытие/открытие из трея и тихий запуск без окна. Проверки не используют личные аккаунты.
